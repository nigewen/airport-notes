## 使用小技巧

- **TikTok**：首次打开别用香港节点，几乎没速度。先切其他节点再切回香港，或干脆不用香港。
- **AI 访问**：大部分香港节点不能用手机端 ChatGPT（特朗普的可以）；新加坡、台湾节点基本所有 AI 都能用，但新加坡普遍速度一般，良心云的还不错。
- **买的时机**：节假日活动通常便宜很多。
- 建议「一个主力 + 一个便宜备用」，避免单点跑路。
